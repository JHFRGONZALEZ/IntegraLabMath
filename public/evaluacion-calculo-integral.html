💻 PARTE II: Proyecto de Desarrollo de Software (60 puntos)

Construya una plataforma web interactiva para enseñanza de cálculo integral. Valor: 60% de la nota final.

📋 ENUNCIADO DEL PROYECTO

Como estudiante de Desarrollo de Software, usted debe diseñar y construir una plataforma web interactiva que sirva como herramienta didáctica para la enseñanza del cálculo integral. La plataforma debe permitir a los estudiantes visualizar, practicar y comprender los conceptos de integración de manera interactiva.

Requisitos Funcionales (Obligatorios)

1. Visualizador de Sumas de Riemann

El usuario puede seleccionar función, intervalo [a,b], número de rectángulos (n) y tipo de suma (izquierda, derecha, punto medio). Se muestran los rectángulos sobre la curva en tiempo real.

2. Cálculo paso a paso

La plataforma muestra el desarrollo completo: Δx, puntos de evaluación, tabla de valores, suma y resultado final con fórmulas renderizadas en LaTeX/KaTeX.

3. Gráfica de convergencia

Una segunda gráfica muestra cómo la suma Sₙ converge al valor exacto cuando n crece.

4. Múltiples funciones

Al menos 4 funciones predefinidas (x², sin(x), eˣ, etc.) y opción de ingresar función personalizada.

5. Tabla de convergencia

Tabla que muestra los valores de S_izq, S_der, S_med y el error para diferentes valores de n.

6. Interfaz profesional

Diseño responsive, modo oscuro, navegación clara y experiencia de usuario pulida.

Requisitos Técnicos

Frontend

  • HTML5 semántico
  • CSS3 (o Tailwind CSS)
  • JavaScript/TypeScript
  • Canvas API o SVG para gráficas

Librerías permitidas

  • KaTeX o MathJax (fórmulas)
  • React o Vue (opcional)
  • Chart.js o D3.js (opcional)
  • Cualquier librería justificada

Funcionalidades extra (bonus)

  • Animación de n creciente
  • Exportar resultados (PNG/TXT)
  • Comparación de tipos de suma
  • Valor exacto con antiderivada

Entregables

  • Código fuente completo
  • README.md con instrucciones
  • Demostración en vivo
  • Documento de diseño
